### Writes and authoritative invariants

- Factual logging: `mutations.periods.logPeriodStart({startDate,timeZone?,startCertainty?})`, `logPeriodEnd({endDate,timeZone?,endCertainty?,periodEventId?,expectedAuthorityVersion?})`, `updatePeriodEvent({periodEventId,startDate,endDate?,timeZone?,startCertainty?,endCertainty?,promoteStartCertainty?,promoteEndCertainty?,expectedAuthorityVersion?})`, `deletePeriodEvent({periodEventId,expectedAuthorityVersion?})`, `updateCycleSettings({cycleLength?,periodLength?,predictionPaused?})`. Backend enforces date/timezone, overlap/authority and capability-specific semantics. D-012 still blocks destructive lifecycle decisions; do not call deletion a completed account-erasure flow.
- Partner factual assistance: `assistLogPeriodStart({startDate,startCertainty?})`, `assistLogPeriodEnd({endDate,endCertainty?,periodEventId?,expectedAuthorityVersion?})`, `correctAssistedPeriodEvent({periodEventId,expectedAuthorityVersion,startDate,endDate?,endCertainty?,promoteStartCertainty?,promoteEndCertainty?})`. **Critical historical-plan correction:** D-009 approves accepted-immediately assisted records; there is no generic pending approval queue. The primary person's later correction/tombstone has final authority.
- Pain: `mutations.painLog.createOrUpdatePainLog({date,painScore,tags,note?,timeZone?})`. - Relationship: `mutations.couples.generatePairingCode({})` is an **action** returning a short-lived code, `linkPartnerWithCode({code})` a mutation returning success/error union; `revokePartnerAccess({})` and `updateSharingSettings({sharingPain?,sharingPhase?,sharingPeriodWrite?})` require current server permissions. - Chat: `mutations.messages.send({body})`, `markDelivered({messageId})`, `markReadThrough({messageId})` (legacy `markRead` alias), `react` and `clear`; preserve relationship-epoch, monotonic receipt and revocation fences. Never retry ambiguous offline health/chat writes as if acknowledged.
- Inbox: `mutations.notifications.setMyPreference({purpose,inAppEnabled,localReminderTime?:string|null})`; `markMyInboxItemRead({itemId})` and `dismissMyInboxItem({itemId})`.
